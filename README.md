# EV-Connect

## Project Description
EV Connect is a website designed to help users
find electric vehicle charging stations and
other vehicle facilities in Brunei Darussalam.

## Project Objectives
- Display EV charging station information.
- Help users find petrol stations, car washes,
  tyre air pumps and parking facilities.
- Provide station and facility details.
- Support user registration and login.
- Provide booking features for EV Charging where implemented.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Main Features
- Homepage
- EV charging station listings
- Vehicle facilities listings
- Station and facility details
- User registration and login
- Booking forms

## Project Files
- HTML files: Website structure
- style.css: Website design and layout
- JavaScript files: Interactive features
- PHP files: Server-side processing
- database.sql: Database structure and sample data

## Installation and Setup
1. Install XAMPP.
2. Copy the project folder into the htdocs folder.
3. Start Apache and MySQL.
4. Open phpMyAdmin and import the provided SQL file.
5. Configure the database connection if required.
6. Open http://localhost/ev/ in your browser.
